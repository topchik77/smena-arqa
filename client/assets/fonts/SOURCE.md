# Golos Text

Variable TrueType font bundled locally so the interface does not depend on a font CDN at runtime.

- Source: [Google Fonts distribution](https://github.com/google/fonts/tree/main/ofl/golostext).
- Upstream project: [googlefonts/golos-text](https://github.com/googlefonts/golos-text).
- Original filename: `GolosText[wght].ttf`; local filename: `GolosText-Variable.ttf`.
- Retrieved: 2026-10-06.
- License: SIL Open Font License 1.1, included in `OFL.txt`.
- Designers: Alexandra Korolkova and Vitaly Kuzmin; released by Paratype.

The font itself is unmodified. The license text accompanies the bundled font.
